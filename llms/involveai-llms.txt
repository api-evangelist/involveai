# Involve.AI

> Involve.AI was an AI-driven customer intelligence platform for customer success and revenue
> teams. It unified data from CRM, support, product-usage and billing systems to calculate
> customer health scores and power an Early Warning System that predicted churn and surfaced
> renewal and upsell opportunities, using a 9Factor model over qualitative and quantitative
> signals. **The company has been renamed and its product surface retired: involve.ai now
> redirects to Jeeva AI, and the Involve.AI application host no longer resolves.** Involve.AI
> never published a public developer API — it integrated by taking admin-granted read access into
> a customer's source systems and writing results back into the system of action.

## Status

- [Renamed to Jeeva AI](https://www.jeeva.ai/): involve.ai and www.involve.ai both redirect to the successor brand. Jeeva AI is profiled separately at https://github.com/api-evangelist/jeeva-ai
- Retired application host: `https://app.involve.ai/` is NXDOMAIN — its CloudFront target no longer resolves
- Retired web origin: `https://www.involve.ai/*` returns Cloudflare 522 on every path but the root redirect
- Retired api host: `https://api.involve.ai/` returns Cloudflare 530 — the DNS record exists, no origin is configured

## APIs

There are none. Involve.AI published no REST API, no GraphQL endpoint, no MCP server, no AsyncAPI
or webhook catalog, no agent card, and no SDK on any public registry. Contract discovery was run
against every Involve.AI host (`api.`, `app.`, `city.`, `www.`) for `/openapi.json`,
`/openapi.yaml`, `/swagger.json`, `/v1/openapi.json`, `/api-docs`, `/docs`, `/redoc`, `/graphql`,
`/apis.json` and the `/.well-known/` discovery surface, and every probe missed.

Configured connections, not developer calls. Documented in the company's own knowledge base:

- [Salesforce: enable Involve.ai access, profile setup and security token](https://city.involve.ai/platform-setup-and-integrations-56/salesforce-enable-involve-ai-access-profile-setup-and-security-token-128)
- [Setting up Zendesk for Involve.ai access](https://city.involve.ai/platform-setup-and-integrations-56/setting-up-zendesk-for-involve-ai-access-127)
- [Pendo setup guide](https://city.involve.ai/platform-setup-and-integrations-56/pendo-setup-guide-220)
